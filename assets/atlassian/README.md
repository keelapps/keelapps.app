# Atlassian product icons

`jira.svg`, `confluence.svg` and `bitbucket.svg` are Atlassian's own product
icons, copied unmodified from the `@atlaskit/logo` package (version 23.3.1,
`<product>/icon`), with only the CSS custom properties resolved to the default
colours they already named.

Atlassian's brand guidelines for Marketplace partners allow these on our own
website to say which product an app works in, on three conditions: use them as
they are (no recolouring, cropping or combining with the Keelapps mark), keep
them current, and never let them stand for Keelapps itself. They sit next to a
product's name — a filter, a card's product line, a footer heading — and
nowhere else. When Atlassian updates its icons, replace these files from a
newer `@atlaskit/logo` rather than editing them.

The apps' own icons are in `/assets/apps/`, copied from each app's repository
(`docs/brand/app-icon.svg`, the file uploaded to its Marketplace listing) with
the comment block removed. Change an icon there, then copy it here.
