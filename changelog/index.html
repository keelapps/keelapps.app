keelapps/What's new

What's new

The changes worth knowing about in every Keelapps app, newest first. Each one is listed in the month we finished it, and every one is live in the version you install today.

Small wording fixes and dependency updates are left out. If an app is missing something you need, tell us what it is. Whoever answers your request also writes the code.

November 2026

  1. New

    AccessLens for Jira

    Explore → By group shows who is in a group and where else the group is used: product access, notification schemes, filters and dashboards, with a CSV export. A new Groups and members page in project settings shows project admins the same, once a Jira admin turns it on. Answers JRACLOUD-11009.

  2. New

    Releases for Bitbucket

    First version. Every tag gets a page with its release notes, the pull requests and approvals since the previous tag, the builds on the tagged commit and the files in Downloads. Answers BCLOUD-11404.

  3. New

    Coverage for Bitbucket

    First version. Coverage and changed-line coverage on every pull request, every test result, a card in the sidebar and a merge check with thresholds. Answers BCLOUD-15935.

  4. Improved

    Coverage for Bitbucket

    The pipe is listed in Bitbucket's official Pipelines integrations, and the setup steps use it the way that list shows it.

  5. New

    Sort Pages for Confluence

    A previous / next page macro. It links to the pages before and after the current one, and to its parent, and never links a page the reader cannot see.

  6. New

    All Jira and Confluence apps

    Each Jira and Confluence app has a Get started page inside the app: where to open it, the first thing to set up, and a link to the full documentation.

  7. Improved

    Recur for Jira

    With no templates yet, the admin page lists the projects you can open and takes you straight to the one you pick. Before, it only said that templates live in projects.

  8. Improved

    Signoff for ConfluenceEvergreen for ConfluenceCurator for Confluence

    If someone has taken back the app's access to their account, the app asks them to allow it again.

  9. Fixed

    Satchel for Jira

    Find attachments says “No attachments found” when nothing matches. Before, the page stayed as it was and the button looked broken.

  10. Improved

    Satchel for Confluence

    The move preview lists the other pages that show a file you are about to move.

  11. Improved

    Satchel for Confluence

    The page dialog shows its title while it loads and, on a page with no files, offers to open Satchel for the whole space. The Manage attachments dialog has a Close button.

  12. Security

    Mail Templates for Jira

    A project's Mail Templates page reads only that project, and only for people who can see the project.

  13. Improved

    AccessLens for JiraSatchel for Jira

    Follows Jira's light or dark theme.

  14. Improved

    AccessLens for Jira

    A signed-off review shows the reviewer's name and a readable time instead of an account id and a raw timestamp. The id stays in the CSV export.

  15. Improved

    AccessLens for Confluence

    Snapshot pickers show when each snapshot was taken, without an id tail.

  16. Improved

    Recur for Jira

    The schedule reads “every 1 day” or “every 2 weeks” instead of Day(s) and Week(s).

  17. Improved

    Counts read “1 page” and “3 pages”, never “page(s)”.

  18. Improved

    Each app shows its own icon and name in the Jira, Confluence and Bitbucket menus, instead of a generic one.

October 2026

  1. New

    AccessLens for Confluence

    Read-only AI tools for Rovo agents and for AI clients such as Claude, through Atlassian's Forge MCP support. They stay off until an admin turns them on.

  2. New

    AccessLens for Confluence

    Reports pages that an edit restriction higher in the tree does not cover. Confluence does not pass edit restrictions down to child pages.

  3. Fixed

    Digest for Jira

    In time zones where the clock changes at midnight, a digest set for midnight no longer goes out the evening before.

  4. Security

    Every admin function checks that the caller is an admin each time it runs, not only when the page opens.

  5. Fixed

    Signoff for ConfluenceEvergreen for Confluence

    Settings pages stop asking for access on every visit.

  6. Fixed

    Curator for Confluence

    A first-time user can allow the app access, and a page that fails to load says so instead of spinning.

  7. Improved

    Sort Pages for Confluence

    When the app has no access to a page, it says that is why the page cannot be sorted.

  8. Quality

    All Jira and Confluence apps

    Each app's test check fails if the tests cover less than 100% of the code, counting lines, branches, functions and statements.

September 2026

  1. Security

    Mail Templates for Jira

    Never emails a comment restricted to a group or role, or a service project's internal note. Jira's own notifications already respect both, and now Mail Templates does too.

  2. Improved

    Mail Templates for Jira

    Rules can send to groups. The preview shows the email the recipient reads, not the template source.

  3. Fixed

    Recur for Jira

    An issue is never created before its time, and none is lost when a template is saved just before it is due. Every time zone is on offer, and “Starting from” defaults to today in the template's zone.

  4. Fixed

    Recur for Jira

    Two templates due in the same hour both keep running. Before, one of them could stop for good while still showing Active.

  5. Fixed

    Digest for Jira

    Changes are listed oldest first, so an issue that was unassigned and then assigned reads in that order. New subscriptions start in your time zone, not UTC.

  6. Improved

    AccessLens for Confluence

    Group grants show the group's name instead of an id. By group and By user list the restricted pages that name the group or person, and whether that lets them in.

  7. Fixed

    AccessLens for Confluence

    A signed-off review keeps its rows and its export when its snapshot is deleted.

  8. Security

    Signoff for Confluence

    Nobody can approve their own request, and an app account cannot be asked to approve. The audit CSV is safe to open in a spreadsheet.

  9. Fixed

    Evergreen for Confluence

    Blog posts and restricted pages work like other pages, and the dashboard shows a change made from the byline straight away instead of after the next daily scan.

  10. Improved

    Prefill for Jira

    A form's page shows its full share link. The builder lists Jira's required fields first and shows each error next to its field.

  11. Fixed

    Satchel for Confluence

    Moves, deletes and undos run as the person who started them, step by step from the page. Before, they could fail with only a “failed” row in the activity list.

  12. Security

    Satchel for Jira

    An inventory shows only the issues the person looking can open. Deleting removes only the files the preview listed, and the audit trail keeps every record for 400 days.

  13. Security

    Curator for Confluence

    The label catalogue and the history of every batch moved to Confluence settings, which only site admins can open. Archiving and moving check the person's own permissions.
