How to find restricted pages in Confluence Cloud

Confluence Cloud · Updated 26 November 2026

An auditor wants every restricted page and who it is restricted to. A teammate says a page vanished from the tree. Or you are about to turn on Rovo and want to know what is locked before it starts answering questions. All three come down to one list that Confluence Cloud only gives you one space at a time.

We build AccessLens for Confluence, which lists restricted pages across spaces, so read the last section with that in mind. Everything before it works on any paid Confluence Cloud site with no app installed.

What Confluence Cloud gives you

As of November 2026 there is one built-in list, documented in Atlassian's page on who can find content:

  1. Open the space.
  2. Go to Space settings, then Content, then Restricted.

Space admins can open it. It covers that space only, so on a site with forty spaces it is forty visits. Two other facts shape everything below:

  • The Free plan has no page restrictions. If your site is on Free, there is nothing to find.
  • View restrictions are inherited, edit restrictions are not. A page under a view-restricted parent is hidden from everyone the parent hides it from, with nothing set on the page itself. An edit restriction stops at the page it is on (CONFCLOUD-5095, open since 2006 with 974 votes).

The requests to do better are old too: CONFCLOUD-31974 asks for site admins to see all restricted pages, and CONFCLOUD-73066 for a list of all of them. Both are Gathering Interest.

Atlassian does publish a knowledge base article, How to list pages with restrictions, but it is SQL against the Confluence database and applies to Data Center only.

If you have a handful of spaces, stop here. Open the Restricted list in each one and you have your answer.

Why one person cannot see a page

That is a different question, and on Premium Confluence answers it: open the page's restrictions dialog and inspect a user's permissions. The report shows whether the page, the space or the product is what lets them in or keeps them out. It checks one person on one page at a time.

Every space, with the REST API

For the whole site, a script works. It needs two calls: list the pages in a space, then read each page's restrictions. We checked these calls on our own test site in November 2026. Create an API token, find the space's numeric id with /wiki/api/v2/spaces?keys=KEY, then: 

SITE=https://your-site.atlassian.net
AUTH="you@example.com:YOUR_API_TOKEN"
SPACE_ID=123456

url="/wiki/api/v2/spaces/$SPACE_ID/pages?limit=250"
while [ -n "$url" ]; do
  page=$(curl -s -u "$AUTH" "$SITE$url")
  for id in $(echo "$page" | jq -r '.results[].id'); do
    curl -s -u "$AUTH" "$SITE/wiki/rest/api/content/$id/restriction/byOperation" |
      jq -r --arg id "$id" '
        (.read.restrictions.user.size + .read.restrictions.group.size) as $view
        | (.update.restrictions.user.size + .update.restrictions.group.size) as $edit
        | select($view + $edit > 0)
        | [$id, "view:\($view)", "edit:\($edit)"] | @tsv'
  done
  url=$(echo "$page" | jq -r '._links.next // empty')
done

It prints one line per page that has a restriction of its own, with how many users and groups the view and edit restrictions name. Three things to know before you trust the output:

  • It only finds restrictions set on the page itself. The restriction call does not report inherited ones (CONFCLOUD-71108). To find pages hidden by a parent, read each page's ancestors (/wiki/api/v2/pages/{id}/ancestors) and check whether any of them is view-restricted.
  • It cannot list what the token's account cannot see. A page that is view-restricted away from that account is not in the page list at all, so it is missing from your output with no gap to show for it.
  • It is one request per page. On a large site that is tens of thousands of calls, and Confluence will slow you down with rate limits.

A native endpoint for listing restricted pages is on Atlassian's tracker as CONFCLOUD-76815, marked In Progress. Until it ships, the loop above is the way.

Questions

How do I see all restricted pages in a Confluence Cloud space?

Open the space, then Space settings, Content, Restricted. Space admins see the list there. It covers one space at a time.

Can I list restricted pages across every space in Confluence Cloud?

Not on one screen. You either open the list in each space, or run a script against the REST API that reads each page's restrictions. Atlassian's own query for this works only on Data Center, where you can query the database.

Are page restrictions inherited by child pages?

View restrictions are: a page under a view-restricted page is hidden too. Edit restrictions are not inherited (CONFCLOUD-5095, open since 2006).

Why can't I restrict a page in Confluence?

Page restrictions are not available on the Free plan. They come with the paid plans.

How do I check why one person can't see a page?

On Premium, open the page's restrictions dialog and inspect that user's permissions. It shows where in the content, space and product the access is allowed or denied, for one person and one page at a time.

Where AccessLens fits

AccessLens for Confluence, which we make, does the script's job from Confluence administration. Its Restrictions tab lists the restricted pages in every space it scanned: view, edit or both, who each restriction names, and, for a page hidden by an ancestor, which ancestor. It also flags restrictions that are probably mistakes, such as one naming a group that cannot see the space at all (a restriction only narrows access, so it gives that group nothing), or a page only one person can read. Each space's list exports to CSV.

It has the same blind spot as the script: a page that is view-restricted away from the app is invisible to the app. The difference is that it tells you. Press Confirm on a space and it compares the pages you can see with the pages it can see, and reports the gap as a number. By default it checks up to 200 pages per space and marks a bigger space as partial; Settings switches that to a full scan. It only reads, and it is free on sites with up to 10 users.
