keelapps/Guides

How-to guides for Jira and Confluence Cloud admins

Each guide answers one question admins ask often. It starts with what Jira or Confluence can do on its own, then the workarounds, and only then the apps that help, ours included.

  1. Jira and Confluence Cloud · 16 October 2026

    Before you turn on Rovo: check who can see what in Jira and Confluence

    Rovo and AI tools connected through the Atlassian MCP server only show what a user can already see. That makes old over-sharing easy to find. What to check in Confluence and Jira before you roll Rovo out, and the settings you have for Rovo itself.

  2. Confluence Cloud · 15 October 2026

    How to get a page approved in Confluence Cloud, on any plan

    Confluence Cloud has page approvals on Premium and Enterprise only. How to use them, how to run a simple sign-off on Free and Standard with statuses and page history, and what to check before you pick an approval app.

  3. Jira Cloud · 12 October 2026

    How to create recurring tasks in Jira Cloud

    Jira Cloud's Set to recur repeats a work item up to monthly. How to set it up, how to build quarterly, yearly or first-Monday tasks with an Automation rule, what each costs, and how to stop recurring tasks piling up.

  4. Confluence Cloud · 9 October 2026

    How to move attachments between pages in Confluence Cloud

    Confluence Cloud moves an attachment to another page one file at a time. The built-in steps, a REST call that moves many files and keeps their history, what a move breaks, and when to move the page instead.

  5. Jira Cloud · 8 October 2026

    Which Jira projects can a user access?

    Jira Cloud has no screen that lists every project one person can reach. How to get the answer from Jira itself with one REST call, how to find out why, and what to capture before someone leaves.

  6. Jira Cloud · 7 October 2026

    Which Jira projects can a group access?

    Jira Cloud has no screen that starts from a group. How to find every project a group can reach with the REST API, the four traps that make scripts wrong, and what else to check before deleting a group.

  7. Jira Cloud · 7 October 2026

    Jira permission audit: who can access what in Jira Cloud

    How to audit Jira Cloud permissions: what auditors ask for, what the built-in screens can and cannot show, a REST API procedure, how the options compare, and a quarterly access review checklist.

  8. Jira Cloud · 7 October 2026

    How to download all attachments from Jira Cloud

    Jira Cloud downloads attachments one issue at a time. Four ways to get every attachment from a JQL search or a whole project, a script you can run today, how they compare, and how to find what is using your storage.

  9. Jira Cloud · 7 October 2026

    How to customize Jira Cloud notification emails

    Jira Cloud's notification emails cannot be edited. What you can change natively, how Automation's Send email works as a template, the costs of each approach, and how to avoid duplicate mail.
