Satchel questions

Can Jira Cloud download all attachments from a project?

Not from the issue view. Download all works on one issue at a time. Across issues you need a site backup with attachments, a REST API script, or an app. The request for a native option, JRACLOUD-68871, has been open since 2018.

Where is Satchel on a Jira issue?

In the issue's right column, under Apps. It is also under the View app actions button below the issue title.

How big can a Satchel zip be?

Up to 1 GB and 5,000 files per archive by default, and 512 MB per file. A larger selection is refused with the number of archives it needs, so you can download it in parts.

Does Satchel upload or change anything in Jira?

It never uploads or edits. The only write call in the code deletes an attachment, and bulk delete is off until a Jira administrator turns it on.

Can I get back an attachment I deleted?

No. Jira Cloud has no recycle bin for attachments (JRACLOUD-81027), and Satchel cannot undo a deletion. Download a copy before deleting anything in bulk.

Does Satchel find exact duplicate files?

It finds candidates: files with the same name and the same byte size. Jira gives no content hash, so proving two files identical would mean downloading both.

What is free?

Everything, on sites with up to 10 users. Above that, the single-issue zip and the single-file download stay free on every install.

What is not in Satchel yet?

Uploading attachments, inventories across several projects, scheduled inventories, and content-hash duplicate detection. Confluence attachments are handled by Satchel for Confluence.
