keelapps/Satchel/Documentation

Download all attachments on one Jira issue

Jira can already do this for most issues: in the issue's attachments section, ··· → Download all. Satchel's issue panel covers the cases where that is not enough.

Download as zip

Every attachment on the issue in one archive, of up to 1 GB and 5,000 files. It works past 150 attachments too, where Jira falls back to a list without previews or thumbnails (JRACLOUD-81747).

Download one file

Each file has its own Download button that saves it straight to your disk, without opening the preview first. This one is never behind a licence check.

What the archive guarantees

  • Duplicate filenames are renamed, never overwritten. Three files called screenshot.png arrive as three files.
  • Anything missing is named. If a file could not be included, a note inside the zip says which one and why.

A long download shows progress and can be cancelled.
