Download attachments from a JQL search or a whole project

Jira Cloud downloads attachments one issue at a time. Collecting the files behind a search or a project has been an open request since 2018 (JRACLOUD-68871). Satchel does it from the project page.

Steps

  1. Open the project, then Satchel in the project's navigation.
  2. Filter the list of issues and attachments, or type JQL for anything more specific. The JQL box runs as you, across any project you can see.
  3. Select rows, or take the whole result, and download.

The archive is foldered by ISSUE-KEY/, so the files arrive sorted by the issue they belong to.

Limits

  • 1 GB and 5,000 files per archive by default. An administrator can lower both.
  • 512 MB per file. A larger file is left out and named in the archive.
  • A selection over the limits is refused, with the number of archives it would need. Narrow the JQL or the filter and download it in parts.

Large projects

The scan behind a project-wide result runs as a background job with a checkpoint, so a large project finishes rather than timing out, and closing the tab does not lose the work.

For the ways to do this without an app (a site backup, or a REST API script), see the guide How to download all attachments from Jira Cloud.
