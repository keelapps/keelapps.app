Site switch and hourly email limits

Jira administrators get a site page under Settings → Apps → Mail Templates for Jira. It has a site-wide off switch, hourly send limits per project and for the whole site, and the list of projects that have rules configured.

Hourly limits

By default a project can send 200 emails an hour and the site 1,000. Both are whole numbers you can change; the site limit cannot be set below the per-project one, since no project could then reach its own limit.

The limits exist because a bulk edit of five hundred issues is five hundred events. When a limit is reached, the remaining events are recorded as Hourly limit reached instead of being sent.
