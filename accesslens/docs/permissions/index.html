Permissions AccessLens requests

AccessLens reads. It makes no write requests to Jira, and it cannot call anything outside Atlassian.

Scopes

ScopeWhat it is for
read:jira-workEnumerate projects; read project roles and permission schemes
read:jira-userRead the user identities returned alongside group members and role actors; the app makes no separate user-lookup call
manage:jira-configurationRead group members. The app writes no configuration and issues no write requests at all. This is the classic scope Jira accepts for reading group members (its granular alternative, read:group:jira, is still in beta), and without group members “which projects can this person reach” is unanswerable.
storage:appStore snapshots, reviews and settings in Atlassian-hosted app storage

Where the data lives

There is no external permission, so Forge blocks outbound calls at the platform level. Snapshots, reviews and settings sit in app storage on Atlassian's infrastructure, and CSV files are built in your browser. The privacy policy lists what is stored and where.
