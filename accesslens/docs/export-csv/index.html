Export permissions to CSV

Lookups, snapshots, diffs and sign-off records all export to CSV.

The file

Files are generated in your browser as UTF-8 with a byte-order mark and CRLF line endings, so non-ASCII project names survive a round trip through Excel. Nothing is uploaded anywhere to build them.

What the header says

  • Snapshot and lookup exports name the snapshot, the scan window, and any capability that was degraded.
  • Diff exports name the two snapshots compared.
  • Sign-off exports name their snapshot and any degraded capability.

The scan window matters because a full-site scan is not transactional: see One scan at a time.
